# Pre-Order Food in College Canteen System

A web-based application designed to simplify food ordering in a college canteen. 
Students can browse food items, manage their cart, and place orders conveniently 
through WhatsApp.

## Features

- Interactive food menu with categories and prices
- Add and manage food items in the shopping cart
- WhatsApp integration for order placement
- Option to provide delivery or contact address details
- Additional notes for order instructions
- Simple and user-friendly interface
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation and Setup

1. Clone this repository:

   git clone https://github.com/kartikkontikall0-max/preorder-food-in-college-canteen-system.git

2. Open the project folder.
3. Open `index.html` in your browser.
